# Devops-Р02
Практическая работа №2 Автоматизация в Linux
Цель работы
Разработать bash-скрипт для получения температуры и влажности в заданном городе и настроить автоматическое обновление данных на веб-сервере nginx.

Ход работы
1. Настройка веб-сервера
Установлен nginx и настроен проброс порта 8080 → 80 в VirtualBox. Проверена доступность сайта по адресу http://127.0.0.1:8080.
<img width="1920" height="1020" alt="image" src="https://github.com/user-attachments/assets/2909989e-03ca-4a84-bf5e-7f00a5719072" />

2. Получение и обработка данных

С помощью curl получены данные о погоде в Перми с сервиса wttr.in в формате JSON. Для извлечения температуры и влажности использована утилита jq.

3. Создание bash-скрипта

Разработан скрипт weather.sh, принимающий название города в качестве входного параметра и выводящий город, температуру, влажность и время обновления.

Исходный код представлен в файле weather.sh.

4. Автоматизация

Настроено задание в crontab:

***** /home/ubuntu/weather.sh Perm > /var/www/html/index.html

Скрипт запускается каждую минуту и записывает результат в индексный файл веб-сервера.

5. Проверка результата

Проверена работа сайта и автоматическое изменение времени последнего обновления.
